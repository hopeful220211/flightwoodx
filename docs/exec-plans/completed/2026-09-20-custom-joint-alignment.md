## 实现与边界

- 添加、鼠标/触控吸附统一读取自制源与槽占用；载入后复核作品、源修订和数量，不重复占用，不写入已切换作品。没有接口的独立摆放明确提示尚未连接。

- 旧混合连接仅纠正精确匹配旧算法的姿态，连带子件刚性移动；无连接的旧重叠件、任意手动姿态不猜测，不做数据库迁移。
- 存储、鉴权、API输入均不新增字段；发布须同步 Web 和包含新版 geometry 的 API。旧 API 不应与新混合姿态前端混用；回退也需前后端配套，保留作品和源数据。
