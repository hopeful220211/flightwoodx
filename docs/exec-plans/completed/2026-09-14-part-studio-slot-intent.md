# 零件孔槽用途与插入位置

> 状态：本地实现与验收完成，未发布
>
> 更新时间：2026-09-14
>
> 适用范围：自制零件绘制中的普通切孔、板内插槽、边缘插槽与方向提示
>
> 替代关系：取代将2mm默认矩形切除称为拼接槽的含混交互；不改变官方连接规则或制造验收边界

## 范围与验收

- 在 `flightwoodx-review`、`codex/home-hero-honors-2026-09-13`、HEAD `ea1f8ca` 接续相关未提交工作，保留此前颜色/布局/孔槽修复。
- 普通矩形切孔按二维拖动范围绘制，可自由缩放。明确选择边缘插槽或板内插槽后固定窄边为名义板厚2mm，保留长向尺寸与平移，不允许锚点、数值或Shift绕过。
- 板内插槽对应另一块板边缘插片，从板面正面或背面插入；边缘插槽从指定边缘向内插入，不能把任意孔视为已有连接。显示位置/方向及配对要求。
- 检查槽是否真的位于板内或形成完整边缘凹口；无作用的普通切除继续不影响预览。错误保留编辑与预览，阻止将失效插槽称为有效。
- 验证孔槽创建、缩放、变更用途、移动、撤销、镜像、保存及恢复；覆盖390×844、768×1024、1440×900，并运行harness与完整CI。

## 证据边界

- 槽设计、几何位置与插入示意不等于两个具体零件已配对。现有自制件自动装配限制不擅自解禁；官方卡扣缺精确二维来源，不能借用类型伪造兼容。
- 名义2mm不包含木板厚度偏差、激光切缝或加工配合补偿；需要实际试片，不能承诺直接插合或结构安全。
- 本轮不发布、不改正式数据、不增加加工保证。

## 调研依据

- UC Davis TechFoundry：https://techfoundry.ucdavis.edu/laser-cutting ，区分板边tab与板内slot的T接、边缘双槽的X接。
- SOLIDWORKS Tab and Slot：https://help.solidworks.com/2024/english/SolidWorks/sldworks/r_tab_slot_propertymanager.htm ，分别定义tab尺寸与slot偏移。
- Ponoko：https://help.ponoko.com/en/articles/4527166-interlocking-3d-laser-cut-designs ，材料厚度偏差、切缝和配合试验。

## 进度

- 初查根因：原 slot 只在创建时给普通 cut 矩形默认 2mm 窄边，后续缩放与参数输入未保留槽用途，也没有持久化插入位置或方向。
- 当前实现：普通切孔、边缘插槽、板内插槽已分开；插槽保留用途和入口方向，数值控件与两个长向锚点保持 2mm 窄边。用途改回普通切孔或实体时移除槽标注，撤销历史保留对应编辑状态。
- 共享契约：`UserPartDef` 新增可选 `jointGuides`，每项保存 `id / kind / x / y / lengthMm / axis / entry`；最多32项、id唯一、窄边由 `USER_PART_THICKNESS_MM` 派生。旧记录仍可缺省，不借用 `sockets`，不增加已配对或已验证字段。
- 共享校验：新增 `@fwx/geometry → @fwx/parts-schema` 依赖，共用契约及板厚常量；`validateJointGuides` 对最终布尔几何核对完整矩形内孔或指定入口的连续三边 U 形切口，支持反向轮廓、循环起点和共线细分，拒绝虚假位置、破坏槽壁、重叠与尺寸不符。序列化坐标容差为0.01mm，尺寸另行校验，不能将两侧容差累加成2.02mm槽宽。
- 位置与保存：编辑器先将边缘槽的板外延伸裁为实际凹口位置，左右镜像保留独立标注及正确入口。`buildUserPartDef` 对几何和标注减去同一 `minX/minY`，舍入后再次复核；无效槽保留画布与三维预览，但禁用保存。API保存并通过DTO返回标注，已保存零件可查看编号、位置和方向；此记录不代表两个具体零件已配对。
- 兼容与失败：PUT省略 `jointGuides` 保留原值，并用新几何复核；显式 `[]` 清空。省略更新读取的记录受所有权及更新时间/原标注条件保护，并发变化返回409，校验失败不覆盖原零件。
- 布局：插槽属性压缩为三行，方向与镜像同行；配合说明移到画布下方状态区，避免增加浮层高度。三尺寸浏览器已核验两个锚点可达、Shift实际拖拽不改变槽宽；主代理与独立代理查看截图无新增遮挡或裁切。
