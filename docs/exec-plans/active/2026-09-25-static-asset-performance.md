# 官网素材加载优化

> 状态：本地验收完成，待用户检查；未发布
>
> 更新时间：2026-09-25
>
> 适用范围：正式版 `980158e` 的首页、关于页、社区展示图片，网页字体、设计页木纹与编辑器代码加载；服务器/CDN 仅做上线前方案
>
> 替代关系：补充当前部署和设计规范，不替代 `CURRENT_STATUS.md`、发布程序或视觉参考

## 目标与边界

- 保留图片、奖项、三架无人机、团队照、社区作品和木纹的内容、完整裁切、相对位置及视觉质量；桌面、平板、手机不得溢出或糊成一片。
- 减少首次访问首页与首次查看三维零件所需下载的字节和关键资源等待；已有浏览器缓存、加载失败与后续导航仍正常。
- 本轮不改文字、业务数据、模型几何、拼接、支付、服务器/CDN 或生产站。用户检查通过后另行授权发布与服务器配置。

## 基线与来源

- 生产资源由成都 ECS 直供；`deploy/README.md` 记载 3 Mbps，Nginx 图片/模型缓存 1 小时、带哈希脚本 7 天，当前未见 CDN 命中。上线时需重新核对。
- 首页三架无人机及四张奖项 WebP 共约 1.14 MB；奖项四图约 635 KB，在桌面四列各约 150 CSS px。首页主图目前要等路由脚本执行后才能被发现。
- 首次木质材质使用 `/textures/wood-board.png`：1024×1024、1,357,471 B；较大官方 GLB 可达 457 KB，较小模型约 87 KB。不要把单次文件下载时间当作所有用户的整页时间。
- 2026-09-25 对正式站一次无缓存桌面 Chrome 样本：导航首字节约 2.06 秒，首个内容约 3.96 秒，主视觉图约 7.34 秒；样本易受地区/网络波动影响，不能作全站用户分位数。
- 现有 WebP、gzip 与路由级懒加载保留；官方模型不批量预加载。

## 步骤

1. 为首页主视觉、荣誉图及关于页团队照提供匹配实际显示宽度和设备像素密度的响应式文件；仅首页最关键主图在 HTML 预发现，其余资源按可见性与优先级下载。
2. 以原 PNG 为视觉基准生成较小木纹格式，确认板面颜色、细纹、明暗和重复贴图不变；改首次材质加载地址，保留可回退原件。
3. 将设计欢迎页不需要的编辑器代码推迟到进入对应模式时加载；网页字体转换为同字形的 WOFF2。社区静态展示卡使用已有轻量图，大图和用户上传 URL 不改。
4. 对照同一网络条件和三种屏宽测：首页首图/首屏字节、关于页及社区图片、设计页材质与 GLB 请求、渲染截图、资源 200、控制台、横向溢出；量化压缩前后差异。
5. 运行相关 Web 测试、完整 `pnpm run ci`，同步 `CURRENT_STATUS.md` 和本计划结果，交本地网址由用户检查。用户确认后单独规划 OSS/CDN、缓存与发布，并核对历史 OSS 403、回退和公网多地区指标。

## 停止与回退

- 图片主体、奖项文字、木纹细节或接口模型失真时，不以更小体积覆盖原效果；提高质量或保留原资源。
- 改动只在独立 `codex/static-perf-2026-09-25` 分支；删除新资源引用即可回退，不触及生产版本、数据库和服务器。

## 实际结果

- 首页三架无人机和四张荣誉图保留原素材，按显示尺寸生成 WebP 候选并通过 `srcset` 选择。主图 HTML 预加载且仅请求一次；其余图片按优先级与可见性加载。七图原版合计 1,143,692 B；实测选图合计约 422,640 B（390 px、3 倍屏）或 330,050 B（1440 px、2 倍屏），分别减少约 63% 和 71%。
- 关于页团队照片保留内容与比例：手机选择 1152 px 文件 176,746 B，平板选择 1440 px 文件 256,994 B，桌面选择 1788 px 文件 336,408 B；原 PNG 为 3,463,728 B。三种屏宽均未裁掉主体或横向溢出。
- 木纹使用同尺寸高质量 WebP，1,357,471 B 降为 159,796 B（约减少 88%），加载失败时自动回退原 PNG；原木纹、材质设置、几何和模型文件不变。原版与转换版像素比对 PSNR 约 42.94 dB。实际 Chrome 绘制矩形后，三种屏宽均显示木纹、`data-wood-ready=true`，无页面脚本错误。
- Open Sans 同源字体转换为 WOFF2，532,636 B 降为 280,216 B（约减少 47%），原 TTF 保留。设计欢迎页推迟下载两种编辑器模块，进入相应模式后再加载。社区仅将六张内置作品卡封面指向已有 WebP，总量由 2,633,372 B 降为 183,144 B（约减少 93%）；用户上传和详情大图不变。
- 最终 `pnpm run ci` 通过，含测试、检查和生产构建；相关新增和回归测试通过。实际 Chrome 在 390×844、768×1024、1440×900 检查首页、关于页、设计页木纹和社区卡：目标图片返回 200、无横向溢出、无页面脚本错误。预览地址 `http://127.0.0.1:4195/`；此静态预览不连接真实 API，社区完整数据和登录业务不属于本轮验收。
- 尚未提交、推送或部署，正式站未改。真实国内访问速度须待用户确认后再配置静态分发/CDN、缓存，并以公网多地区指标核对；本地字节减少不能直接等同于公网加载时间减少。
