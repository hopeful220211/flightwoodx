## 字体

本站采用参考页实际使用的字体顺序：

```css
font-family: "Open Sans", "PingFang SC", "Microsoft YaHei", "Helvetica Neue",
  "Hiragino Sans GB", "WenQuanYi Micro Hei", Arial, sans-serif;
```

英文及数字使用本地提供的 Open Sans；中文在 macOS 使用苹方、Windows 优先微软雅黑，后续按上述顺序回退。不同系统的中文字形会随系统字体变化，这与参考页的机制一致，不承诺跨系统逐像素相同。

- 主要字重：正文 400、部分产品标题 500、章节标题 600。统一现有 display / grotesk / mono 工具类的字体族，数据增加等宽数字属性，不另外引入展示字体。
- 首页 `FLIGHT / WOOD X` 是唯一保留的字体例外：原 Montserrat Black 900、原字体文件、`font-synthesis: none`、`clamp(64px, 9vw, 130px)`，不改成 Open Sans。
- Open Sans 从 Google Fonts 的官方字体仓库取得，遵循随文件保存的 SIL Open Font License 1.1；不提取 DJI 商标、图片或私有图标字体。字体族一致，不声称 Google Fonts 当前文件与保存页嵌入版本逐字节相同。来源和摘要见 `apps/web/public/fonts/OpenSans-SOURCE.md`。

### 字距、行距和文字处理

- 字号与行高均为 CSS px，不能用截图的物理像素直接换算。表中 `16/24` 表示16px字号、24px行高；400为常规，500为中等，600为半粗。
- 页面默认字距 `-0.02em`，即16px正文为-0.32px。`.site-section-title` 与 `.site-section-lead` 显式使用 `normal`；导航14px为-0.28px；`.about-hero h1`、`.about-page section h2` 和 `PageContainer` 常规页面标题为 `-0.03em`。沿用对应语义类，不对所有文字统一压缩字距。
- 常规文字正体。不得恢复中文斜体、超粗字、超宽字距或给全部标题添加英文大写。段落默认不两端强制对齐，也不插入空格排齐中文。
- 正文默认16/24；紧凑说明14/20或14/22；次要标签12/20。长篇协议和隐私正文沿用文档页15/32、左对齐，不能为了紧凑按导航字号排版。
- 普通段落之间16px；标题与引言16px，手机12px；引言最大宽694px。长段落左对齐，短开场与章节引言可以居中。
- 数值对比沿用 `font-variant-numeric: tabular-nums`，不因此更换字体。项目里的 `font-mono` 当前也是同一字体族，不代表代码等宽字体。
- Tailwind 的 `bold`、`extrabold`、`black` 已映射到600；新页面优先明确写 `font-normal`、`font-medium`、`font-semibold`，不要根据类名推断显示为700或900。
- 首页大品牌字额外保留行高0.95、字距-0.025em；这不是通用标题规格，不用于账号、关于或工具页面。

### 功能色不是装饰色

- 开孔、切除、删除沿用对应控件的红色语义；二维切除轮廓当前为 `#dc5252`，插接口落点为 `#b91c1c`。普通轮廓与选择使用行动蓝，不能把这两类操作画成相同图标和颜色。
- 成功、提醒、错误沿用现有组件的绿、橙、红。主题入口分别提供 `#22c55e`、`#f59e0b`、`#ef4444`；细文字和轮廓使用组件现有深色变体，不把亮色机械用于白底小字。
- 错误图形定位沿用橙色 `#b45309` 和虚线；状态不能只靠颜色，还要有名称、图标、选中状态或短说明。
- 木色、真实木纹、官方标志中的金色、奖项原图及 Blockly 分类色保留。木色用于材料与真实资产，不再作为普通按钮的第二主题。
- 首屏允许已有低饱和灰渐变：`#e2e6e9 → #f7f8f9 → #d8dee2`；关于页沿用 `#e6eaed → #f7f9fa`。不新增霓虹、紫蓝发光、无用途彩色渐变。

## 布局映射与新页面选用

1. **首屏**：导航、居中品牌与短说明、紧凑按钮、下方无人机主体。保留本站大型品牌字与已有木质无人机图片；荣誉放在产品图下方，原图完整呈现。
2. **产品视频**：窄间隔后的全宽深色区域，16:9 直角画面、最大 1200 px，同时限制高度以保留完整播放器。仍然点击原位播放，不增加弹窗。
3. **平台功能**：居中章节标题，三列图片在上、文字在下，24 px 间隔。手机顺序堆叠。
4. **设计工作台**：浅灰大区域，标题与说明集中在上，原循环演示居中大幅展示，不加暂停按钮。
5. **步骤与荣誉**：步骤用对齐数字、细分隔线和正文；荣誉保留原真实文案、主办方链接，使用深色通栏和低对比本站零件线稿。
6. **使用对象**：三列整幅照片，标题在图片上方区域居中，渐变保证白字可读；不添加原来没有的业务承诺。
7. **真实评价**：保留全部原文和轮播交互，缩小头像，改用白色留白与 24/36 正文，不再使用大面积蓝框。
8. **关于我们**：居中开场、本站无人机图片、标题与介绍两列、完整团队大图、奖项条目及联系区。手机号、微信和合作入口不改变。
9. **社区、账号、作品与隐私**：沿用参考字体、字重、文字色、内容宽度、灰色背景与细边框；保留现有内容结构、权限及所有表单行为。
10. **二维 / 三维 / 编程编辑器**：共用同一字体、文字色及中性面板；按钮通常6px、输入框4px、浮层8px圆角，按控件类型执行。保留双画布、固定属性窗口、工具栏、44px操作目标与全部设计行为；没有从 DJI 官网虚构一个对应编辑器布局。

新页面按任务选最近的现有排布，不强制每页都放首屏大图、三列功能、评价和行动入口。介绍类参考关于页；作品与社区参考对应列表；操作密集页面参考工作台；登录注册参考账号表单；长文参考协议页。沿用其内容层级，只添加当前任务需要的区块。

## 标志、图标和控件

### 标志

- 全站导航高度64px；标志容器44×24px，原标志等比完整显示；名称18/24、600、字距-0.03em，与标志相隔8px、垂直居中。容器尺寸不是要求把方形标志拉伸成矩形。

- 注册标题下说明按用户指定断行：第一行“注册后可保存无人机设计和程序，”，第二行“并在其他设备登录查看。”；不改字体和字号。
- 图标与品牌名称组成一个对齐单元，不能各自依赖文本基线，不能一大一小，也不能给其中一个另加装饰外框。
- 保留原标志文件，不重新生成商标、不使用 DJI 标志。深浅背景下保证可辨认，不能把整体透明度调低到影响识别。

| 注册提交按钮 | 14px、600、48px高，铺满表单；8px圆角 | 未填完整/未同意协议/请求中不可提交；不是胶囊形 |
| 输入框 | 14px，左右16px、上下10px；1px灰边、4px圆角 | 标签在上，间隔6px；蓝色聚焦边及轻焦点环；错误就近说明 |
| 注册勾选 | 20×20px，标签操作区至少44px高；12/24说明 | 默认未选；协议为可打开的文字链接；与可选统计分开 |
| 图标按钮 | 按用途复用16/18/20px图标；形状工具当前21px图标 | 图标不等于点击面积，周围保留可触控区域；所有工具有可读名称 |
| 工具提示 | 12px、500，白字深灰底、4px圆角 | 悬停/键盘焦点显示；离开、点击或Escape收起；禁用工具也可说明用途 |

同一区域保留一个主要操作，其余使用次按钮、描边或文字链接。加载时显示实际进度状态并防止重复提交；禁用时不可响应且视觉减弱，不能只换颜色。注册页现有禁用透明度60%，不是所有控件必须强行同值。

默认焦点为可见轮廓；已有全局3px轮廓、偏移3px，紧凑输入和工具按其现有2px/1px焦点样式。不得统一 `outline: none` 却不提供替代，也不得通过改变边框厚度让控件跳动。

### 圆角、边框和阴影按用途选择

- 大照片、产品视频、作品封面展示：0px圆角，通常无阴影；靠布局与内容区分，不围成层层圆角框。
- 输入与小标签：4px；工作台导航与工具按钮：通常6px；浮层、表单容器与对话框：8px。头像为圆形，紧凑营销按钮可用64px胶囊。
- 不把“统一风格”理解为所有元素都直角或都胶囊。项目 Tailwind 的 `rounded-md=4px`、`rounded-lg=6px`、`rounded-xl/2xl=8px`，不能按默认框架值推断。
- 默认不加阴影。需要表达悬浮的工具栏/属性窗口沿用 `0 4px 20px rgba(0,0,0,.1)`；已有普通轻阴影为 `0 10px 30px rgba(0,0,0,.06)`，不用蓝色发光。
- 注册表单保留现有宽而柔和的投影；标志本身不加。大图、视频和普通内容不照搬该表单投影。

## 图像、视频与动态效果

- 2026-09-23：首页“飞行测试”使用用户提供的平板飞行演示照片，减弱原图黄调；文件为 `apps/web/public/resource/picture/flight-testing-neutral.webp`。其他图片、文字和布局不变。
- 2026-09-23：首页第四张获奖荣誉图采用用户提供的最新合成图，包含金芦苇工业设计奖。沿用前三张图的 2298×872 画布和响应式布局，保持可见大小一致。

- 产品图完整展示结构，优先 `object-fit: contain`；封面和环境照片可 `cover`，但不能裁掉核心产品、团队人物或奖项关键信息。真实团队/奖项图优先保留原比例。
- 章节主图与文字共用内容边界；三列内图片使用相同高度/比例。现有功能图片桌面280px高、平板210px高、手机4:3；已有受众照片桌面488px、平板400px、手机420px，不能把这些局部高度当作全部图片的固定高度。
- 视频默认16:9、直角，不拉伸。演示动图保留静音循环、行内播放、无常驻暂停按钮；产品介绍视频继续按实际播放器规则点击播放，两者不要混淆。
- 图片上叠字时才用局部暗遮罩保证可读，保留原照片颜色；不用给白底正文加阴影补救对比度。
- 普通按钮颜色过渡200ms；现有滚动出现为600ms、轻微16px位移。沿用现有实现，工具输入、拖动、选中反馈即时响应，不添加入场动画阻碍操作。
- 首页三架无人机保留原有构图：近景上下11px、倾角1°、周期6.4秒；中景7px、0.7°、8.2秒；远景4px、0.4°、10.6秒。错开起始相位，仅移动图片，不改变布局；离开视口或后台暂停，系统减少动画时保持静止。
- 尊重减少动态效果设置；不能隐藏必要内容，也不能把每段都做成浮动、旋转或连续视差。

## 工具页的固定交互要求

- 二维和三维标题栏同高、同字体、同起始位置。参考设置留在上方，绘图工具留在画布底部；不要再把多行工具和属性塞到画布上方。
- 选中属性放在固定位置、按需出现；未选择时隐藏但不能挤动画布或改变工具位置。选中框为细蓝线与可操作锚点，不恢复粗大描边。
- 图形创建成功即回到选择工具；未完成和失败时不强行切换。图标工具有最短可懂的名称提示，不能只靠猜图标。
- 插接口与普通矩形开孔图标、用途区分；可操作边缘有落点/指针反馈，无效位置说明如何操作。固定2mm板厚、木纹与现有几何规则不能因风格统一被改写。
- 错误只解释当前问题和修改方法，不在两边重复提示，不用常驻免责声明占据画布。页面正常时让内容与画布优先。
- 现有工具局部仍有40px按钮、11px辅助文字等紧凑实现，不把它们升级为新页面默认值；新增触控操作以至少44px目标为准，具体碰撞与遮挡用真实浏览器检查。

## 新页面的执行步骤

1. 确认页面用途、内容、主要操作和已有相似页面；检查用户是否指定局部例外。
2. 从下表找到共享组件、样式与实际页面，复用已有布局关系。没有对应元素时，先按相同用途组合，不新增整套主题或依赖。
3. 先确定内容宽度、对齐线与段落顺序，再选字号、颜色、圆角。使用本文默认值；确需偏离时说明用途和理由。
4. 设计加载、空白、成功、失败、选中、禁用及小屏状态。长标题、中文换行、协议链接、数值输入不能因压缩而失效。
5. 实现后检查三个屏宽的实际呈现。局部修改只检查相关组件及受影响路径，不把每轮细节调整扩大成全站重做；按项目开发与发布规则执行必要测试。
6. 用户确认的后续改动同步到本文件和相应共享样式；不要只在聊天里记住，也不要另建一份相互冲突的设计规范。
